Debug & Refactor

Hoạt động 3: Tối ưu mã nguồn CSS do AI sinh ra.

1. Tìm thuộc tính trùng lặp

Gộp các thuộc tính có cùng giá trị.
Loại bỏ các thuộc tính mặc định không cần thiết.
Không dùng CSS thừa như float: left.

2. Thay giá trị cứng bằng biến CSS

:root {
    --spacing-unit: 8px;
}

.card {
    margin-bottom: calc(var(--spacing-unit) * 3);
    padding: calc(var(--spacing-unit) * 3);
}

3. Dùng Shorthand Properties

/* Cách dài */
margin-top: 16px;
margin-right: 16px;
margin-bottom: 16px;
margin-left: 16px;

/* Refactor */
margin: 16px;

4. Evaluation

Dùng Inspect Element (F12) để kiểm tra Box Model, padding, margin và xác nhận không có thuộc tính CSS dư thừa.
